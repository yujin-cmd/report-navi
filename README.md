# Report Navi

AI 기반 의사결정 정보 완결성 추적 시스템의 HIMEC 공모전 3분 시연용 웹 MVP입니다.

회의록처럼 이미 말한 내용을 요약하지 않고, 보고 전에 확정한 Decision Set을 기준으로 아직 전달되지 않은 결론·근거·전제·리스크·요청사항을 실시간 추적합니다. 시간이 부족해지면 남은 필수 정보만으로 경로를 다시 구성합니다.

## 실행

요구 환경:

- Node.js 20 이상
- pnpm 9 이상
- 데스크톱 Chrome 또는 Edge 권장

```bash
pnpm install
pnpm dev
```

터미널에 표시되는 로컬 주소를 Chrome/Edge에서 엽니다.

production build와 미리보기:

```bash
pnpm build
pnpm preview
```

단위 테스트:

```bash
pnpm test
```

## 환경변수

현재 MVP는 외부 AI API를 호출하지 않으므로 필수 환경변수가 없습니다. PDF 텍스트와 사전 준비된 표현 변형을 이용한 로컬 분석·매칭으로 전체 데모가 동작합니다. 이후 LLM 분석 endpoint를 연결할 때에도 API 키는 브라우저에 넣지 말고 Netlify Function 같은 서버 측 환경변수로 보관해야 합니다.

## AI 없이 데모 모드 실행

1. 시작 화면의 기본 목적지로 `자료 업로드로 이동`을 누릅니다.
2. `샘플 자료 불러오기`를 누릅니다.
3. 8장 HTML 데모 덱을 확인하고 `AI로 Decision Set 생성`을 누릅니다.
4. 생성된 8개 항목을 검토한 뒤 `보고 시작`을 누릅니다.

샘플 자료의 모든 수치·조건은 공모전 시연용 가상값이며 실제 HIMEC 내부자료가 아닙니다.

## 3분 시연 절차

1. 샘플 자료를 불러오고 5개 유형의 Decision Set이 생성되는 장면을 보여줍니다.
2. 보고자 화면 하단 `106.2kW 발화`를 누르거나 “최대 냉각부하는 106.2킬로와트입니다”라고 말해 근거 항목이 자동 체크되는 것을 보여줍니다.
3. `리스크·요청만 남기기`로 준비된 상태를 만들고 Slide 5에서 다음 페이지로 이동해 누락 토스트를 확인합니다.
4. `남은 시간 30초`를 눌러 필수 항목 중심의 경로 재탐색을 발동합니다.
5. `Evidence Navi`에서 샘플 질문 “106kW의 근거는?”을 실행해 Slide 4를 찾습니다.
6. `보고 종료`를 눌러 필수 전달률, 미전달 정보, 실제시간, 재탐색·근거검색 기록을 확인합니다.

## 주요 구조

```text
src/
  components/          화면과 발표자/프로젝터 UI
  data/demo.ts         8장 가상 덱, Decision Set, 예상 질문
  hooks/               Web Speech API 연속 인식
  lib/pdf.ts           PDF.js 렌더링과 페이지 텍스트 추출
  lib/report.ts        정규화, 로컬 매칭, 재탐색, 근거 검색
  App.tsx              wizard 상태와 localStorage 지속성
public/demo/           샘플 데이터 메타정보
```

실시간 구간은 LLM을 호출하지 않습니다. 사전 확정된 `title + detail + variants`와 발화를 로컬에서 정규화한 뒤 토큰 coverage와 문자열 유사도를 계산합니다. `%/퍼센트/프로`, `kW/킬로와트`, 쉼표가 포함된 숫자 표기를 통합합니다.

## 알려진 제한사항

- Web Speech API는 브라우저·OS 정책과 네트워크 상태에 따라 제공되지 않을 수 있습니다. 이 경우 하단 텍스트 입력으로 동일한 매칭 흐름을 시연할 수 있습니다.
- 일반 PDF의 fallback은 텍스트 기반 규칙 분석입니다. 스캔 이미지 PDF에는 OCR이 없으므로 텍스트가 추출되지 않을 수 있습니다.
- 업로드 PDF의 렌더 이미지는 현재 탭 메모리에만 유지됩니다. 새로고침 후에는 PDF를 다시 선택해야 합니다. Decision Set과 종료 리포트는 localStorage에 저장됩니다.
- BroadcastChannel을 지원하지 않는 오래된 브라우저에서는 프로젝터 창 동기화가 제공되지 않습니다.

## 배포

`netlify.toml`이 포함되어 있습니다. Netlify에서 저장소를 연결하면 `pnpm build` 후 `dist/`가 배포됩니다. 외부 AI를 추가하기 전까지 별도 비밀값은 필요하지 않습니다.
